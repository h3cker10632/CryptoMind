🧪 Strategy Researcher (auto-discovers new strategy shapes; promotes only on honest out-of-sample metrics)

Searches a safe rule DSL over the shared technical features, backtests every candidate on a purged walk-forward, and promotes only those clearing a deflated-Sharpe bar that prices the number of candidates tried (the false-strategy tax). Promoted rules become the bandit-weighted discovered ensemble arm — measured, never a blind copy. Enable researcher_enabled (and optionally researcher_use_llm) in ⚙️ Settings; it also runs itself every ~6h.

🎲 Polymarket — prediction-market sleeve (paper; standalone book)

Separate paper bankroll from the crypto book. Signals are transparent heuristic priors (momentum, mean-revert, favourite–longshot fade, order-flow) — not claimed alpha. The engine only OPENS bets that clear the edge & cost-viability gate, and the shared bandit + online model MEASURE whether the heuristics actually predict resolutions. Enable the sleeve and auto-trade in ⚙️ Settings. Live on-chain execution is a separate, disabled-by-default switch.
